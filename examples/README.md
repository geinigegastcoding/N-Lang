# N-Lang-voorbeelden

[bewegen.nlang](bewegen.nlang) is letterlijk het taalvoorbeeld uit de gebruikersopdracht, met gewone spaties in plaats van HTML-spatiecodes. De [specificatie](../docs/taal/syntaxis.md) beschrijft het gewenste gedrag. Het bestand is een ontwerpeis, geen bewijs van een werkende compiler. Er is nog geen verwachte binaire uitvoer: het bytecodeformaat moeten jullie eerst ontwerpen.

Voeg later kleine voorbeelden per ondersteunde constructie toe. Schrijf erbij welke compilerversie ze ondersteunt. Ongeldige invoer hoort bij de [testfixtures](../tests/README.md); de map `docs/pws/voorbeelden/` bevat uitsluitend voorbeelden van documentatievormen.
