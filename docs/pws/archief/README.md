# Archief

Deze map bewaart vervangen PWS-context voor auditbaarheid. Actuele documenten verwijzen alleen naar het archief als historische ontwikkeling relevant is.

## Archiveringsregels

- Verplaats alleen documenten die aantoonbaar zijn vervangen of niet meer actief zijn.
- Verander hun status in `superseded` of `archived`.
- Voeg bovenaan de datum, reden en een link naar de actuele opvolger toe.
- Behoud inhoud en oorspronkelijke bronverwijzingen.
- Werk de canonieke index en alle inkomende links bij.
- Archiveer logboekregels en werklogs niet; zij blijven op hun vaste plek als proceshistorie.

Er zijn momenteel geen gearchiveerde documenten.
