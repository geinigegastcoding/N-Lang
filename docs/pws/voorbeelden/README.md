# Voorbeelden

Deze map toont vorm, detailniveau en bewijsdiscipline. De inhoud is illustratief en mag nooit als echte N-Lang-historie, onderzoeksdata, testuitvoer of bron worden gebruikt.

## Beschikbare voorbeelden

- [`voorbeeld-werksessie.md`](voorbeeld-werksessie.md) — een volledig ingevulde maar fictieve technische werksessie.
- [`voorbeeld-bronnotitie.md`](voorbeeld-bronnotitie.md) — een invulvoorbeeld voor een belangrijke externe bron.
- [`voorbeeld-onderzoeksredenering.md`](voorbeeld-onderzoeksredenering.md) — hoe bronfeit, waarneming, interpretatie en conclusie uit elkaar blijven.
