# Bronnotities

Maak hier een kleine notitie voor een belangrijke of herhaald gebruikte bron wanneer een tabelregel in `bronnenregister.md` onvoldoende context biedt.

## Bestandsnaam

Gebruik `bNNN-korte-titel.md`, waarbij `BNNN` overeenkomt met het bron-ID in het register.

## Inhoud

- volledige referentie en stabiele URL/DOI;
- bewijsstatus en type bron;
- relevante pagina's of secties;
- korte samenvatting in eigen woorden;
- bruikbare claims met nauwkeurige locatie;
- kwaliteitsbeoordeling en mogelijke belangen;
- hoe de bron in het PWS wordt gebruikt;
- wat de bron nadrukkelijk niet aantoont.

Kopieer geen volledige auteursrechtelijk beschermde publicaties. Bewaar korte noodzakelijke citaten binnen redelijke grenzen en verwijs voor de rest naar het origineel.

Zie [`voorbeeld-bronnotitie.md`](../voorbeelden/voorbeeld-bronnotitie.md) voor de gewenste vorm.
