# Inbox

Deze map is een tijdelijke landingzone voor relevante projectinformatie waarvan de juiste bestemming nog onzeker is.

## Regels

- Gebruik de inbox niet als standaardnotitiemap.
- Geef elke notitie `status: needs-review`, een ontvangstdatum en een concrete herkomst.
- Behoud de oorspronkelijke formulering wanneer betekenis anders verloren kan gaan.
- Verwerk de notitie zo snel mogelijk naar onderzoekskader, bron, besluit, voortgang, werklog of archief.
- Link verwerkte informatie en archiveer of verwijder de lege tijdelijke verpakking alleen als de inhoud aantoonbaar elders behouden is.
- Plaats hier geen persoonsgegevens, geheimen of ongeanonimiseerde deelnemersdata.

Er staan momenteel geen open inboxnotities.
